About this game

Shadow System is an original, lightweight hunter-fantasy RPG inspired by dungeon-progression anime. It is an unofficial fan-style game and is not affiliated with the anime's rights holders. It uses original, emoji-based visuals and no external downloads.

Best played in your phone browser. Keep the downloaded HTML file to reopen the game. Browser storage may differ between browsers, so export a save backup before clearing browser data.
